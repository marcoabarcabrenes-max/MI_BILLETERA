# MI BILLETERA

Proyecto Android de una app personal para controlar ingresos y gastos.

## Funciones de esta versión
- Saldo automático.
- Registrar ingresos y gastos.
- Categorías.
- Historial de movimientos.
- Datos guardados localmente con SharedPreferences.
- Colones costarricenses.
- Diseño oscuro elegante con detalles dorados.
- Botones visuales con iconos.

## Cómo generar el APK
1. Instala Android Studio en una computadora.
2. Abre esta carpeta como proyecto.
3. Espera a que Gradle sincronice.
4. Ve a Build > Build APK(s).
5. El APK de depuración quedará en `app/build/outputs/apk/debug/app-debug.apk`.

No requiere servidor ni cuenta externa para guardar los movimientos.
